# Algorithms and Data Structures

*(made for study, not for actual use)*

### Welcome everyone!

This semester I struggled a bit with the University course "Algorithms and Data Structures" , the workload between all the lectures was too big for me and I ended up not understanding the course as much as I wanted.

Now ( 2026 August summer break ) I have the time and mental clarity to deep dive into the course content. I will not share private University material for obvious reasons, but I will attempt to build EVERYTHING I encounter in this course to better understand it and hopefully pass the exam with a good grade.

### The material I will use

My professor let the students use a 6 page paper full of all the pseudocodes that we encountered in the course, I will try to only use that to get a better understanding of the material I will use in the actual exam, but I also give myself the opportunity to use free online material for studying and suggestions ( No copying allowed anyway ).

**Note on AI:**
```
We live in an era where LLM can generate good code without the need of you actually understanding it, I'm not so against it if a real developer with a good understanding of coding does it. But let's be real, I'm in University for a reason and letting a machine do the things I should be learning and understanding doesn't go down with me. ( personal opinion )
I still think it can be a good instrument to better study and understand things but you have to be very critical of your use and I know it can be really hard sometimes, but again, this is just my personal opinion, you do whatever you want as long as it's ok with you :)
```

### The language I decided to use

I chose Java because it's an OOP language that I already know ( from previous Uni courses ) and I like for this type of things because it gives me the opportunity to concentrate more on the actual developig of things without worrying too much about a complex syntax.

**Note on variable names:**
```
I know for certain that some people are not going to like my choice for some variables, both because some are written with uppercase characters and also because I use some rather useless conventions like storing a length variable for some types of Data Structures also when Java already gives the opportunity to retrieve it automatically.
This is done because I want my files , both for Data Structures, Methods and Functions to be as close to the papers I'm given for the exam.
```
